## About

I'm interning at Nutanix right now, and outside work I build things to see how they actually function: a shell, a retriever, a log parser. Most of my recent time has gone into AI agents, mainly making them answer from real documents, call tools, and fail safely. I'm now reading into distributed systems and search, and my next projects will go there.

I like measuring what I build. If I can't test it, I don't trust it.

## What I'm working on

- **Internship at Nutanix**, currently ongoing.
- **[helpdesk-agent](https://github.com/HimSlayer001/helpdesk-agent)**, an IT help desk agent that runs locally with Ollama. It retrieves from a knowledge base, calls tools to raise and look up tickets, and refuses prompt injection before the model sees it. It has an eval harness covering retrieval, tool choice, citations, injection blocking and latency.
- **[logsleuth](https://github.com/HimSlayer001/cliLogger)**, a Python command-line log analyzer. In progress.
- **[rag_to_riches](https://github.com/HimSlayer001/rag_to_riches)**, RAG written from scratch to learn the parts. In progress.
